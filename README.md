# Guide to Comparing Domestic Franchises

**Creator:** Student project  
**Project:** Compare three South Korean fried-chicken franchise brands using one consistent metric.

## About
This responsive, single-file website compares BBQ, bhc, and Kyochon Chicken using reported franchise-location counts. It includes a language selector (English, Nepali, Uzbek, Filipino, and Vietnamese), comparison criteria, a sortable table, four Google search-query examples, and source links. All CSS and JavaScript are embedded in `index.html`; no external API is required.

## Tools used
- ChatGPT for drafting and organizing the comparison page
- HTML, CSS, and JavaScript
- Google search query operators for research practice
- Korea Fair Trade Commission (KFTC) source pages

## Important data note
The counts displayed in the page (BBQ 2,316; bhc 2,228; Kyochon Chicken 1,361) are preliminary figures from a secondary summary and have **not been independently confirmed against each brand's official KFTC disclosure in this project**. Verify the same base year and definition in the official portal before treating the values as confirmed. Do not interpret store count as revenue, profit, or quality.

## Three details to personally verify or modify before submission
1. Open the KFTC disclosure comparison portal and confirm the 2024 year-end store count for each brand; replace any figure that differs.
2. Record both the publication date of each source and the base year covered by its figures.
3. Test the language selector, both sorting buttons, reset control, and source links in a desktop browser and on a smartphone.
